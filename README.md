# خودرویار (KHODROYAR) – نسخه ۰.۲

اپلیکیشن فارسی Flutter برای ثبت خودرو و مدیریت سوابق سرویس.

## اجرای پروژه
نیازمند Flutter SDK و Dart سازگار با نسخه 3.3 یا بالاتر:
```bash
flutter pub get
flutter run
```

## امکانات پیاده‌سازی‌شده در این نسخه
- رابط فارسی و راست‌چین
- داشبورد خلاصه خودروها و سرویس‌ها
- ثبت چند خودرو، پلاک، شماره شاسی و کیلومتر
- به‌روزرسانی کیلومتر خودرو
- ثبت سرویس‌های روغن، فیلترها، لنت، تسمه، باتری، شمع و بازدید فنی
- ثبت فاصله کیلومتری و تاریخ اختیاری سرویس بعدی
- محاسبه سررسید کیلومتری/تاریخی درون برنامه
- ذخیره محلی داده‌ها با SharedPreferences
- ایجاد و انتخاب پروفایل فروشگاه‌های همکار به‌عنوان نمونه اولیه

## محدودیت‌های مهم
این نسخه هنوز محصول عملیاتی منتشرشده نیست:
- اعلان زمان‌بندی‌شده سیستم‌عامل هنوز متصل نشده است.
- چندفروشگاهی فعلاً نمونه محلی است و جداسازی امن داده در سرور ندارد.
- ورود پیامکی، ثبت‌نام، نقش‌ها و دسترسی‌ها، API و پایگاه داده ابری هنوز پیاده‌سازی نشده‌اند.
- کیلومتر خودرو به‌صورت خودکار از خودرو خوانده نمی‌شود؛ مالک باید آن را به‌روزرسانی کند.
- تاریخ‌های یادآوری ثبت می‌شوند و وضعیت سررسید داخل برنامه محاسبه می‌شود؛ اعلان بیرون از برنامه در نسخه بعدی افزوده خواهد شد.

## نقشه راه لازم پیش از انتشار
1. بک‌اند و پایگاه داده چندمستاجری (multi-tenant) با جداسازی داده فروشگاه‌ها
2. احراز هویت امن و اتصال مشتری به فروشگاه از طریق کد/QR
3. اعلان محلی اندروید و iOS و پیامک سروری
4. پنل مدیریت وب، گزارش‌ها، مشتریان و کمپین‌ها
5. تست روی دستگاه واقعی، سیاست حریم خصوصی و انتشار فروشگاهی

نام و زبان: خودرویار، فارسی.
